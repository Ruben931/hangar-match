# Hangar Match

Calculateur de vaisseaux **Star Citizen** : tu indiques ton budget aUEC et ce que tu veux faire, l’outil liste les vaisseaux qui correspondent (prix, taille, cargo, lieux d’achat / location).

## Lancer en local

```bash
npm install
npm run dev
```

Ouvre l’URL affichée (souvent `http://localhost:5173`).

## Données

Les prix viennent surtout de [starcitizen.tools](https://starcitizen.tools/) (New Deal / Astro Armada). Ils peuvent changer selon les patchs — édite `public/data/ships.json` pour mettre à jour.
